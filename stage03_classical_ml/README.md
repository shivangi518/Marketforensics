# Stage 03 — Classical machine learning (your first AI)

## Goal
Build features around each big-move case and train a simple model **without peeking into the future**.

## Words to know

| Word | Simple meaning |
|------|----------------|
| Feature | Input clue (e.g. recent volatility) |
| Label | What we try to predict/explain |
| Train set | Data the model learns from |
| Test set | Hidden data used only for checking |
| Leakage | Accidentally using future info (cheating) |

## You will add in this stage
- Feature table builder
- Time-based train/test split
- Decision tree or random forest baseline

## Checklist

- [ ] Features are computed only from data **before** the event day
- [ ] Model trains and evaluates
- [ ] You wrote what failed as well as what worked
